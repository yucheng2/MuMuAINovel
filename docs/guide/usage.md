## 快速开始

### 1. 登录与注册

MuMuAINovel 支持三种登录方式：

- **本地账户登录**：使用邮箱和密码登录
- **邮箱验证码登录**：发送验证码到邮箱登录
- **OAuth 登录**：使用 LinuxDO 账号登录

### 2. 创建新项目

1. 登录后点击「新建项目」按钮
2. 填写项目信息：
   - **项目名称**：你的小说标题
   - **类型**：选择小说类型（玄幻、都市、科幻等）
   - **简介**：简要描述故事背景
3. 点击「创建」进入项目工作区

### 3. 项目工作区

项目创建后进入工作区，包含以下模块：

- **章节** - 创作和管理章节
- **角色** - 管理登场人物
- **大纲** - 规划和生成故事大纲
- **关系** - 可视化角色关系图
- **伏笔** - 管理和追踪伏笔
- **职业** - 管理职业体系
- **设定** - 世界观设定
- **风格** - 写作风格配置
- **灵感** - AI 对话式创作

## 项目管理

### 查看项目列表

在书架页面可以查看所有项目，支持：

- **列表视图**：以表格形式展示
- **书架视图**：以书本样式可视化展示

### 导入/导出项目

- **导出项目**：点击项目卡片右上角菜单，选择「导出」，生成 ZIP 文件包含所有项目数据
- **导入项目**：点击「导入」按钮，上传之前导出的 ZIP 文件

### 项目设置

在项目详情页可以修改：

- 项目名称和简介
- 目标字数
- 小说类型和主题

## 角色管理

### 创建角色

1. 进入「角色」页面
2. 点击「新建角色」按钮
3. 填写角色信息：
   - **姓名**：角色名称
   - **年龄**：角色年龄
   - **性别**：角色性别
   - **性格**：角色性格特点
   - **背景**：角色来历和经历
   - **外貌**：角色外观描述

### AI 生成角色

1. 点击「AI 生成」按钮
2. 描述你想要生成的角色
3. AI 会生成符合描述的角色
4. 可对生成结果进行编辑调整

### 角色组织

支持将角色分组到不同组织：

1. 切换到「组织」标签页
2. 创建组织并添加成员
3. 方便管理大型故事中的势力阵营

### 导入/导出角色

- **导出角色**：将角色列表导出为 JSON 文件
- **导入角色**：上传 JSON 文件批量导入角色

## 章节创作

### 查看章节列表

在章节页面可以：

- 按章节号排序查看
- 查看每章字数和状态
- 点击章节阅读或编辑

### 批量生成章节

1. 进入「大纲」页面生成或选择大纲
2. 返回「章节」页面
3. 点击「批量生成」按钮
4. 选择要生成的大纲
5. 设置生成数量
6. 点击「开始生成」

生成过程支持 SSE 流式输出，实时显示进度。

### 章节分析

1. 选择要分析的章节
2. 点击「分析」按钮
3. AI 会分析章节内容，给出：
   - 章节摘要
   - 情节优缺点
   - 改进建议

### 单章再生

对已生成的章节不满意，可以：

1. 选中章节内容
2. 点击「再生」按钮
3. AI 会基于选中内容重新生成

### 上下文模式

生成章节时支持两种上下文模式：

- **一对一模式**：基于前一张大纲生成
- **一对多模式**：基于所有前文大纲生成

## 大纲管理

### 创建大纲

1. 进入「大纲」页面
2. 点击「生成大纲」或手动添加
3. 可以设置：
   - 大纲标题
   - 大纲内容
   - 章节号（可选）

### AI 生成大纲

1. 描述你想要的大纲内容
2. 选择大纲生成模式
3. AI 会生成完整的大纲树

### 展开为章节

1. 选择要展开的大纲节点
2. 点击「展开为章节」
3. AI 会自动生成对应章节

### 大纲视图

支持树形视图展示大纲层级结构：

```
📁 第一卷 觉醒
  ├── 📄 第一章 异变
  ├── 📄 第二章 入门
  └── 📄 第三章 成长
📁 第二卷 历险
  └── ...
```

## 关系图谱

### 查看关系图

以可视化图形展示角色之间的关系：

- **节点**：代表角色
- **连线**：代表关系
- **颜色**：区分不同关系类型

### 创建关系

1. 进入「关系」页面
2. 点击「新建关系」按钮
3. 选择关系双方（角色 A 和角色 B）
4. 选择关系类型（朋友、敌人、爱人等）
5. 可选填写关系描述

### 预设关系类型

系统预设的关系类型包括：

| 类型 | 描述 |
|------|------|
| 亲人 | 血缘或法律意义上的亲属关系 |
| 朋友 | 友好关系 |
| 爱人 | 恋人或配偶关系 |
| 敌人 | 敌对关系 |
| 主仆 | 主从关系 |
| 师徒 | 传授关系 |
| 同门 | 同一师门 |
| 陌生人 | 不认识 |
| 其他 | 自定义关系 |

### 查看关系详情

点击图谱中的节点或连线，可以查看详细的关系描述。

## 伏笔管理

### 创建伏笔

1. 进入「伏笔」页面
2. 点击「新建伏笔」按钮
3. 填写：
   - 伏笔标题
   - 伏笔内容
   - 伏笔类型（长期/短期）
   - 埋入章节

### 伏笔追踪

- **已埋入**：伏笔已在某章节出现
- **已回收**：伏笔已在后续章节回收
- **未回收**：伏笔尚未回收

### 伏笔上下文

查看伏笔时，AI 会给出：

- 伏笔首次出现的位置
- 可能的回收时机建议
- 与其他伏笔的关联

## 职业体系

### 创建职业

1. 进入「职业」页面
2. 点击「新建职业」按钮
3. 填写：
   - 职业名称
   - 职业类型（主职业/副职业）

描述你想要的职业体系，AI 会自动生成包含名称、类型、阶段的完整职业设定。

- 传统文学风格
- 网络小说风格
- 简洁干练风格

## 提示词工坊

### 功能介绍

Prompt 工坊是调试和优化提示词模板的工具。

### 使用流程

1. 进入「提示词工坊」页面
2. 在左侧编辑器编写 Prompt
3. 点击「发送测试」按钮
4. 右侧查看 AI 响应结果
5. 根据结果调整 Prompt

### 模板变量

支持使用变量占位符：

```
请生成一个{type}类型的角色，名字叫{name}
```

### 保存模板

测试满意后，可以将 Prompt 保存为模板，供后续使用。

## MCP 插件

### 功能介绍

MCP（Model Context Protocol）插件系统允许扩展 AI 能力。

### 支持的插件类型

| 类型 | 说明 |
|------|------|
| HTTP | 基于 HTTP 协议的插件 |
| StreamableHTTP | 支持流式输出的 HTTP 插件 |
| SSE | Server-Sent Events 插件 |
| stdio | 本地命令行插件 |

### 安装插件

1. 进入「MCP 插件」页面
2. 点击「添加插件」按钮
3. 填写插件信息：
   - 插件名称
   - 显示名称
   - 插件类型
   - 服务地址
4. 点击「测试」验证连接
5. 确认后启用插件

### Function Calling

系统会自动检测模型是否支持 Function Calling，并据此启用或禁用相关插件功能。

## 拆书导入

### 功能介绍

将已有的 TXT 小说文件导入为项目结构。

### 导入流程

1. 进入「拆书导入」页面
2. 上传 TXT 文件
3. 系统自动解析：
   - 识别章节标题
   - 统计字数
   - 分析内容结构
4. 预览解析结果
5. 如有错误，可手动修正
6. 确认导入

### 导入模式

- **末章生成**：导入前几章，后续章节由 AI 继续生成
- **整本导入**：导入完整小说

## 灵感模式

### 功能介绍

灵感模式是 AI 对话式引导创作功能，帮助在没有完整大纲的情况下也能创作。

### 使用方式

1. 进入项目的「灵感」页面
2. 与 AI 进行对话
3. AI 会引导你完善：
   - 故事背景
   - 主要角色
   - 情节发展
4. 对话完成后，可将结果保存为项目或大纲

### AIProjectGenerator

在灵感模式中，可以使用 AI 项目生成器，通过描述创意快速创建一个完整的项目框架。

## 常见问题

### Q: 批量生成失败怎么办？

A: 检查以下几点：
1. API Key 是否有效
2. API 余额是否充足
3. 网络能否访问 AI 服务商

### Q: 如何导出我的作品？

A: 在项目列表页面，点击项目右上角菜单，选择「导出」。

### Q: 可以多人协作吗？

A: 目前版本暂不支持多人协作，每个项目属于单一用户。

### Q: 数据存储在哪里？

A: 所有数据存储在配置的 PostgreSQL 数据库中。

### Q: 如何让 AI 生成的章节更符合我的预期？

A: 可以通过以下方式优化：
1. 完善角色设定和世界观
2. 编写更详细的大纲
3. 在「写作风格」中设置偏好风格
4. 在「提示词工坊」中调试 Prompt
